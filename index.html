What the application does

JGC Backups is being developed for the company's designated operator to protect business records and test recovery. It is not a public storage service. This website does not provide access to company records or connect to the live portal.

The planned workflow creates an encrypted recovery set once a week, saves it in a designated private Google Drive folder, retrieves it to verify the saved copy, and tests recovery in a separate, isolated environment. A company-controlled external storage device provides an additional copy when connected.

The normal retention period is two calendar months. The latest verified backup is retained longer if a replacement fails, so a failed run does not remove the last known-good recovery point.

Limited Google Drive access

The application is configured to request Google's drive.file permission. This covers files created by the application or explicitly selected for use with it. Authorization and selection of the backup folder are separate setup steps.

The application does not request permission to read Gmail messages or access all unrelated Drive files. Authorization tokens and backup contents are not published on this website.
