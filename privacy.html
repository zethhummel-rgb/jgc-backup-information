Setup in progress. This policy governs setup and the intended operation of JGC Backups. Automated backups are not yet operational. Publishing this policy does not establish that a backup or recovery test has succeeded.

Operator and purpose

John Gordon Construction Inc. operates JGC Backups for its own business-continuity and recovery needs. Google user data is used only to store, locate, retrieve, verify and manage the application's designated backup files. The application is intended for the company's designated operator, not public registration.

Google data and permissions

The requested Google permission is drive.file: access to files created by the application or explicitly selected for use with it. This can include reading, creating, updating and deleting those files. The application does not request access to Gmail messages or all unrelated Google Drive files.

Data used can include file identifiers, names, sizes, timestamps, integrity information and the contents of backup files. Authorization tokens enable unattended access after the account operator grants consent. They must be held in protected secret storage, not public source code or logs.

Backup information

Recovery sets may include confidential company and personal information: client and employee records, jobs, estimates, purchase orders, work orders, timesheets, documents, and access-control or authentication data needed for recovery. Backup access is restricted to the designated operator and authorized service processes.

Storage, processing and safeguards

The planned destinations are a designated private Google Drive folder, a company-controlled external storage device, and an isolated recovery-test environment. The planned automation host is GitHub Actions in a separate private repository; the recovery database provider is Supabase. These providers process information as needed to deliver their services.

Backup copies must be encrypted before upload. Verification and recovery require decryption in a restricted environment. Temporary working copies must be removed after use under a tested cleanup procedure. Recovery-test data must be isolated from production and outbound business communications. These controls must be implemented and tested before scheduled operation begins.

This public information repository and website do not contain backup files, business records, access tokens or credentials.

Retention and deletion

The normal retention period is two calendar months. The latest known-good recovery set is preserved if replacement backups fail verification. External-device copies can only be updated or removed when the device is connected. Recovery-test copies are retained only for verification and operator review, then removed; the cleanup procedure must be verified before activation.

Deleting a live record does not immediately remove it from historical backups. Subsequent authorized deletions must be considered during recovery. Provider trash and recovery mechanisms can affect when deletion becomes permanent.

Restrictions on use

Google user data is not sold, used for advertising, or used to train generalized artificial-intelligence models. Access and transfers are limited to operating, securing and recovering the company's backup service.

JGC Backups' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Operator controls

The account operator can revoke the application's authorization through Google's connected-app controls. Revoking access stops future authorized access but does not itself delete existing backups or external-device copies. Contact the company below to request review or deletion of retained information.

This information website

This static website has no sign-in, data-entry forms, analytics scripts or application cookies. GitHub Pages hosts it and may process ordinary connection and access information under the GitHub privacy statement. Emailing the contact address shares the information you choose to include in your message.

Changes

This policy will be updated before changes to providers, permissions, data uses or retention take effect. The effective date appears at the top of this page.
